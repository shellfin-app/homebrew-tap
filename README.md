# Shellfin Homebrew tap

Casks for [Shellfin](https://shellfin.app/) (https://github.com/shellfin-app/shellfin). Written by the release workflow of the main repository; do not edit by hand.

```sh
brew install --cask shellfin-app/tap/shellfin
```

Apple Silicon only. Shellfin updates itself; Homebrew does not fight it (`auto_updates true`).
